# yohaku-ig-media

YOHAKU HQで承認したInstagram投稿画像の一時配信用リポジトリです。

- 投稿の間だけ、承認済みの画像を `ig-*` ブランチに置きます。投稿後にそのブランチを削除します。
- このリポジトリは公開されています。公開してよい画像だけを置きます。
- 秘密情報は置きません。
- 手作業での編集は想定していません。

## 恒常アイコン(HQ)

- `hq/apple-touch-icon-180.png`: YOHAKU HQのiPhoneホーム画面アイコン(正式ロゴ・180px)です。HQのNetlify版はサイト全体が認証で保護されているため、アイコンを認証なしで取得できるよう、公開されているこの場所に1枚だけ置いています。
- `ig-*` ブランチの一時画像とは別のもので、投稿後も削除しません。差し替えるときは、HQのアイコン作成手順(`scripts/hq-make-icons.mjs`)で作り直した同じ正式ロゴを使います。
